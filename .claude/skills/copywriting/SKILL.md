# WerkFlow copywriting

Resolve the shared source folder from the repository containing this skill. In werkflow-business, use its docs folder. In werkflow-website, use the sibling werkflow-business/docs folder. Read AGENTS.md and establish source freshness under docs/workflow.md before relying on shared context.

Read docs/copy-standard.md, then the relevant avatar, offer, acquisition, and beta-partnership documents. Apply hormozi-advisor: read docs/library/baseline.md and the relevant book/framework notes before drafting. Deep-read linked modules when the claim or tactic needs detail. The source register and source-cautions.md distinguish source coverage, commentary, and unverified prescriptions.

All copy must be at or below a fifth-grade reading level. Apply this to each publishable unit, not only its average. Use the standard's language-appropriate review. Never claim a measured score without a measurement. If readability remains unverified, keep the copy labeled as a draft awaiting review.

Establish the audience, desired action, channel, and evidence for the claim. Ask only for missing choices that materially change the result. Write natural German with familiar words, short sentences, concrete benefits, and one clear next action. Keep the adult reader's dignity.

Use real offer conditions. Separate future scope from current capability. Do not invent customer quotes, quantified savings, urgency, guarantees, prices, launch dates, or beta-partner endorsements. Read the owning source before asserting a fact.

Before delivery, check every material claim, simplify difficult passages, apply unslop, and perform the readability review. Report any unresolved source or review gap with the draft. Drafting copy does not authorize sending, publishing, or ad spending.
